# 工创小车固件交接文档

> 面向接手此固件的下一位同学。所有内容以当前代码为准（2026-10-04），参数值改了这里也要同步改。

## 1. 项目概况

- 硬件：STM32F407 @168MHz，ST 标准外设库，FreeRTOS，Keil MDK（armcc）。
- 功能：一台「闭环步进麦轮小车」，6 个 ZDT X_V2 闭环步进电机 + 3 个舵机 + 维特 JY901 陀螺仪 + ELRS/CRSF 遥控。
- 电机分配：底盘麦轮 = 1/2/3/4，塔吊升降 = 5，塔吊伸出 = 6。
- 任务周期：三任务全部 10ms（`vTaskDelayUntil`）。

## 2. 硬件接口映射

| 资源 | 引脚 | 说明 |
|---|---|---|
| CAN1 | PA11(RX) / PA12(TX) | 500 kbps，扩展帧(29bit)，过滤器掩码 0 全收，FIFO0 + `CAN_IT_FMP0` 中断 |
| 步进电机 1~4 | CAN 地址 1/2/3/4 | 麦轮底盘（FL/FR/RL/RR） |
| 步进电机 5 | CAN 地址 5 (`MOTOR_HOIST`) | 塔吊升降 |
| 步进电机 6 | CAN 地址 6 (`MOTOR_EXTEND`) | 塔吊伸出 |
| 舵机 | TIM2：CH2=PA1 夹爪 / CH3=PA2 物料平台 / CH4=PA3 云台 | 50Hz，`CCR = angle/range*2000+500` |
| 陀螺仪 JY901 | USART2 PD5(TX)/PD6(RX) 115200 | 自带姿态融合，直接读偏航 `Imu_GetYaw()` |
| 遥控 ELRS/CRSF | UART3/UART5 420000 | `ELRS_Remote_Update()` |
| VOFA 调试 | UART6 460800 | 串口调试 |

## 4. 关键协议与驱动

### 4.1 CAN 步进电机（X_V2）

- 发送：扩展帧 ID = `(地址<<8) | Packet`，数据 = `[功能码, 数据…, 0x6B校验]`；单条命令 >8 字节时拆多帧（Packet 从 0 递增）。
- 响应：ID 同上；`Data[0]` = 功能码或状态（`02`=成功 / `E2`=参数错 / `EE`=格式错 / `9F`=到位返回）。
- **读位置**：发 `X_V2_Read_Sys_Params(addr, S_CPOS)`（0x36）；回包 `Data[0]=0x36, DLC=7`，`Data[1]`=符号(1=负)，`Data[2..5]`=32 位大端位置，**×0.1 = 度**。
- **位置命令** `X_V2_Traj_Pos_Control(addr, dir, acc, dec, vel, pos, raf, snF)`（0xFD）：vel×10、pos×10 大端编码。
  - `raf`：0=相对上次目标 / 1=绝对（相对零点，本项目用这个）/ 2=相对当前位置。
  - `snF`：0=立即执行 / 1=缓冲。
- CAN 稳健性：`CAN_ABOM` 已开（bus-off 自动恢复）；`can_SendCmd` 等邮箱带超时（约 20 万次循环），不会无限卡死。

### 4.2 舵机

`Servo_SetAngle(servo_id, angle)`，50Hz，占空比线性映射。夹爪张开 80° / 闭合 29°。

### 4.3 陀螺仪

维特 JY901，内部 AHRS 融合，`Imu_GetYaw()` 返回 -180~180°，偏航角环用 `PID_Init(..., is_angle_loop=1)`。

## 6. ⚠️ 最重要的坑（本次调试的核心结论）

**同一电机的「位置命令」和「读位置请求」绝对不能在同一拍背靠背发。**

- 现象：电机 5 在上电默认任务里「收到命令但不动」，而测试代码怎么发都能动。
- 根因：发完 `0xFD` 位置命令紧接着发 `0x36` 读请求，读请求紧跟位置命令上总线，把电机**还没处理完的位置命令打断了**。
- 证据：打断点停一下（只发一条命令）电机就能动；测试代码能动是因为它「先发 5 号、再发 6 号」，5 号命令和读之间天然隔了 6 号的 2 帧。
- 解决：**发命令和读位置交错到不同拍**（这一拍发、下一拍读，中间隔 10ms），见 `Tower_Boot_Task` 里的 `boot_phase`。

**通用规则（写任何新电机代码都要遵守）：**

1. 位置命令与读位置不要背靠背，中间至少隔一帧或一个任务周期。
2. 位置命令**每拍重发没问题**（不会打断梯形曲线；之前「重发打断」的说法是错的，已证伪）。
3. 读位置函数必须**循环跳过**先到的 `0xFD` 应答帧（`0x02`），直到收到 `0x36` 位置帧（应答帧抢在位置帧前面到）。
4. 这些电机**不需要 `X_V2_En_Control`**（实测不需要使能，不要加回去）。

### 其他硬约束

- **`delay_ms` 不能在调度器启动后调用**（delay 库是 SysTick 轮询版，`SYSTEM_SUPPORT_OS=0`）。任务里要延时就用 `vTaskDelayUntil` 或拍计数，别用 `delay_ms`。
